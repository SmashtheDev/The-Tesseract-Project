# Screenshots

This directory contains screenshots for the TESSERACT documentation.

## Required Screenshots

The following screenshots are referenced in the Quick Start Guide:

| File | Description | Dimensions |
|------|-------------|------------|
| `01-first-run.png` | Vault selection screen on first launch | 800x600 |
| `02-create-vault.png` | Password setup with strength indicator | 800x600 |
| `03-recovery-key.png` | 24-word recovery key display | 800x600 |
| `04-drag-drop.png` | Drag and drop file import | 800x600 |
| `05-file-browser.png` | File browser with files listed | 800x600 |
| `06-lock-vault.png` | Toolbar with lock button highlighted | 800x600 |

## Capturing Screenshots

To capture these screenshots:

1. Run TESSERACT in development mode
2. Navigate to each screen
3. Use your OS screenshot tool or press `F12` in the app (if supported)
4. Crop to the application window
5. Save as PNG at the recommended dimensions

## Notes

- Use a clean vault with sample files for demonstration
- Ensure no sensitive information is visible
- Recommended format: PNG
- Recommended dimensions: 800x600 for main screens
